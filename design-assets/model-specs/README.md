# Model Asset Specs

Use this folder for reusable model or character asset specifications before generation.

Future examples:

- Founder avatar set
- Board member portraits
- Competitor company mascots or logos
- Office object sprites
- 3D room or object concepts if the Godot version later moves beyond static 2D scenes

All generated outputs must still use image-2 unless the user explicitly approves another model for a specific technical reason.
