## Prompt

Create an isometric pixel-art startup office command center for a business simulation game. The company is an early-stage AI SaaS startup called NimbusAI. Show a readable office floor with distinct rooms for product development, engineering team, sales, servers, reception, and board discussion. The mood is energetic but operational, with warm office lighting, clear desks, computers, plants, meeting room details, and enough visual structure for React overlay labels.

Style: polished 2D isometric pixel art, game UI background quality, bright and readable, no dark blur, no stock-photo look, no oversized decorative gradients. Composition should work as a wide 16:9 stage background with important rooms spread across the frame and enough empty visual pockets for overlay badges.

Avoid: embedded text labels, brand logos other than generic NimbusAI-style signage, realistic photography, unreadable clutter, heavy shadows, distorted people, low-resolution artifacts.

## Usage Notes

- Keep important text as frontend overlays instead of baking it into the image.
- Future versions should preserve the same room layout vocabulary so player orientation remains stable across releases.
- If UI density increases, regenerate a cleaner version with larger empty areas near room boundaries.
