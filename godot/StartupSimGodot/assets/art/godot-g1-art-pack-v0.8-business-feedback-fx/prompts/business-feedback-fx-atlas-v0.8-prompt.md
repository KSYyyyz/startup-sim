# Prompt - business-feedback-fx-atlas-v0.8

Use case: stylized-concept

Asset type: transparent-ready game FX sprite atlas for Godot top-down office management simulation

Primary request: Create a clean 8 columns x 4 rows sprite atlas of small business feedback FX for Startup Sim. Each cell is one distinct, centered, icon-like visual effect that can appear above office tiles, facilities, or employees. The atlas must be usable for slicing into equal cells.

Canvas/layout: single atlas, exactly 8 columns and 4 rows, equal cells, consistent margins, each effect centered with generous padding, no overlapping between cells. No labels, captions, letters, numbers, words, currency symbols, UI panels, or decorative text anywhere.

Scene/backdrop: Create all FX on a perfectly flat solid #ff00ff chroma-key background for background removal. The background must be one uniform color with no shadows, gradients, texture, reflections, floor plane, or lighting variation. Do not use #ff00ff anywhere in the FX subjects.

Columns / semantic categories from left to right:
1. product progress: blue technical spark, abstract blocks and upward energy only, no glyphs
2. sales lead: green signal ping and contact glow, abstract handshake silhouette if needed, no letters
3. cash pressure: plain unmarked gold coin shapes plus red pressure pulse or red gauge mark, absolutely no currency symbols, no dollar sign, no letters, no numbers
4. customer feedback: empty speech-bubble-like glow with star/dot sentiment, no text
5. morale shift: warm heart/sunburst and emotional particles, icon-only
6. server stability: compact server-cloud spark and cyan stability ring, no characters on server
7. upgrade complete: wrench/gear with gold starburst, icon-only, no checkmark glyph if it looks like text
8. training growth: book/skill node with small growth sparks, no letters on book pages

Rows / animation roles from top to bottom:
row 1 small pop marker, row 2 rising float marker, row 3 pulse ring marker, row 4 burst/trail marker.

Style/medium: polished 2D stylized game FX, crisp silhouettes, readable at small size, compatible with top-down office atlas art, soft antialiasing, subtle glow, no photorealism.

Color palette: varied but restrained: blues, greens, golds, reds, warm accents. Avoid dominant purple-only, beige-only, brown-only, or dark-blue-only palette.

Constraints: no readable text, no numbers, no watermark, no people, no large UI cards, no shadows cast onto the background, no contact shadows, no reflections. Keep each effect separated from the chroma-key background with crisp edges for clean alpha removal.
