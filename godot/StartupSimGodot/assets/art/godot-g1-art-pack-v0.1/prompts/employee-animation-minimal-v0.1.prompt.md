Use case: stylized-concept
Asset type: Godot 2D employee minimal animation sprite sheet
Primary request: Create a minimal animation sprite sheet for six distinct startup employee roles.
Scene/backdrop: Perfectly flat solid #00ff00 chroma-key background for background removal.
Subject: A clean 8 columns x 6 rows sprite sheet. Rows are developer, sales rep, operations/product manager, server engineer, HR/recruiter, founder/manager. Columns are walk frame 1, walk frame 2, work frame 1, work frame 2, tired frame 1, tired frame 2, rest frame 1, rest frame 2.
Style/medium: Polished tiny 2D game sprites, top-down/slight 3/4 office view, light pixel-art influence, crisp silhouettes, readable at 32-64 px.
Composition/framing: Each sprite centered in its own cell with consistent scale and generous padding; no overlap.
Role differentiation: Developer hoodie and headphones; sales jacket and tablet/phone; operations cardigan and clipboard; server engineer utility vest and cap; HR scarf and folder; founder older face, vest, rolled sleeves, glasses. Keep silhouettes distinct from row to row.
Animation readability: Adjacent pairs should be similar enough to animate as simple two-frame loops, but visibly different in pose or prop position.
Direction rule: Mix left, right, and front/diagonal orientations across roles; do not make every sprite face right.
Constraints: The background must be one uniform #00ff00 color with no shadows, gradients, texture, reflections, floor plane, or lighting variation. Do not use #00ff00 anywhere in the subject. No cast shadow, no contact shadow, no reflection, no watermark, no text, no labels, no numbers.
