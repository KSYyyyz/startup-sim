# Startup Sim 🚀

**AI客服SaaS创业模拟器** — 一个12回合的策略模拟游戏。

你是一家AI客服SaaS公司的创始人，刚获得100万元种子轮投资。在12个月内，你需要做出产品、营销、团队、融资和战略决策，带领公司走向成功——或面对破产。

## 快速开始

```bash
# 安装依赖
pip install -r requirements.txt

# 开始新游戏
python app.py new --name "你的名字"

# 指定难度
python app.py new --name "创始人" --difficulty hard
```

## 游戏玩法

每回合输入你的决策（自然语言），系统会解析、模拟并展示结果：

```
👉 第1月决策: 研发AI客服核心功能，投入20万

👉 第2月决策: 招聘2名销售，投放百度广告花15万

👉 第3月决策: 见投资人，路演募资
```

### 支持的行动类型

| 类型 | 关键词示例 | 效果 |
|------|-----------|------|
| 🛠️ 产品 | 研发、功能、开发、迭代 | 提升产品评分 |
| 📣 营销 | 广告、推广、获客、投放 | 增加用户和MRR |
| 👥 团队 | 招聘、招人、hire | 提升团队士气 |
| 💰 融资 | 见投资人、路演、募资 | 获得资金但稀释股权 |
| 🎯 战略 | 转型、新市场、扩张 | 提升市场份额和声誉 |

### 状态面板

每回合显示关键指标：

- 💰 现金 / 🔥 月消耗
- 📈 MRR / 👥 用户数
- 🛠️ 产品评分 / 💪 团队士气
- 📊 股权 / 🏛️ 董事会控制力
- ⏳ 剩余现金跑道

## 游戏结局

| 结局 | 条件 |
|------|------|
| 💸 破产 | 现金 ≤ 0 |
| 👋 创始人出局 | 股权<34% 且 董事会<45% 且 跑道<4月 |
| 🎉 A轮融资成功 | (第12月) MRR≥50万 且 产品≥70 且 股权≥50% |
| 😐 勉强存活 | (第12月) MRR≥20万 且 现金>0 |
| 🐌 慢性死亡 | (第12月) 未达到以上标准 |

## 特殊事件

- **⚠️ 跑道警告**: 现金≤3个月 → 士气-5，声誉-2
- **🔴 董事会危机**: 股权<34% + 董事会<50% + MRR增长<5% → 士气-10，声誉-5
- **🚀 产品突破**: 产品评分≥75 → 声誉+8，MRR+5万

## 项目结构

```
startup-sim/
├── app.py                  # CLI 入口
├── config.py               # 配置
├── requirements.txt        # 依赖
├── README.md               # 本文件
├── data/
│   └── scenarios.yaml      # 剧本定义
├── src/
│   ├── core/
│   │   ├── models.py           # Pydantic 数据模型
│   │   ├── state_guard.py      # 状态验证与安全检查
│   │   ├── action_parser.py    # 自然语言解析器
│   │   ├── event_engine.py     # 事件触发引擎
│   │   ├── ending_evaluator.py # 结局判定
│   │   └── turn_engine.py      # 回合主流程
│   └── db/
│       ├── connection.py       # 数据库连接
│       ├── schema.sql          # SQLite 建表
│       └── repository.py       # 数据访问层
└── tests/
    ├── test_state_guard.py     # 状态守卫测试
    └── test_endings.py         # 结局判定测试
```
