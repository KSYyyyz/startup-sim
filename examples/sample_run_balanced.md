## 策略思路

先小规模融资（200万/8%），再交替研发和营销，稳扎稳打。

## 复盘摘要

- **创始人画像**: 技术极客 — 以产品为核心驱动力，稳步推进
- **策略评分**: 综合 100（产品力/增长力/财务力/控制力/风控力全维度优秀）
- **关键转折点**: 3个 — 产品突破/MRR里程碑/现金管理
- **结局叙事**: 技术驱动型 A 轮成功 — 产品口碑带来自然增长

## 成就列表

- 🟢 [common] 产品信仰者 — 产品分达到80+
- 🟢 [common] A轮赢家 — 达成A轮成功
- 🟢 [common] 控制权大师 — 保持股权90%+
- 🔵 [rare] 资本玩家 — 通过融资撬动增长

## 学习点

1. **先融资再发展**：首回合小融资为后续花钱创造空间，避免现金紧张
2. **交替研发+营销**：不要只做研发（产品好但没用户）或只做营销（用户来了留不住）
3. **小步快跑**：每回合5万预算足以稳步推进，大额投入不一定更好
4. **控制股权稀释**：8%的出让保留了92%股权，董事会控制权稳定
5. **12个月节奏**：最后几个月 MRR 快速增长，A 轮条件在第12月达成
